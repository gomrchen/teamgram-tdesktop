# 服务端对接配置

Desktop 客户端连接 **自建 Teamgram** 时的网络、RSA 与 API 配置（非 Telegram 官方数据中心）。

---

## 1. 网关地址（必改）

文件：

```
Telegram/SourceFiles/mtproto/mtproto_dc_options.cpp
```

Teamgram 已用 `@teamgram` patch 替换官方 DC 列表。修改 `kBuiltInDcs` 与 `kBuiltInDcsTest`（建议 **两处 IP 一致**）：

```cpp
const BuiltInDc kBuiltInDcs[] = {
    { 1, "127.0.0.1", 10443 },
};
const BuiltInDc kBuiltInDcsTest[] = {
    { 1, "127.0.0.1", 10443 },
};
```

| 场景 | 建议 IP |
|------|---------|
| 本机后端 | `127.0.0.1` |
| 局域网其他机器上的后端 | 服务器局域网 IP（如 `192.168.1.13`） |
| 公网用户 | 公网 IP 或域名 |

修改后须重新 `configure` 并完整编译。

---

## 2. 端口

| 协议 | 端口 | 后端服务 |
|------|------|----------|
| MTProto TCP | **10443** | `gnetway` |
| MTProto TCP | 5222 | `gnetway`（可选） |
| WebSocket | **11443** | `gnetway` |

客户端写死 **10443**，一般无需改端口，只需保证服务端 `teamgram/etc/gnetway.yaml` 已监听且防火墙放行。

---

## 3. RSA 公钥（须与后端一致）

同文件 `mtproto_dc_options.cpp` 中 `kPublicRSAKeys` / `kTestPublicRSAKeys` 须对应后端 `server_pkcs1.key` 导出的公钥。

更换密钥流程：`teamgram.io/enterprise/docs/更换授权密钥.md`。

---

## 4. 其他 Teamgram 网络 patch

| 文件 | 作用 |
|------|------|
| `mtp_instance.h` | 默认主 DC 改为 `1`（非官方 `2`） |
| `config_loader.cpp` | 禁用官方 SpecialConfig 拉取 |
| `mtp_instance.cpp` | 禁用 HTTP 时间同步到官方域 |
| `mtproto_domain_resolver.cpp` | 禁用官方域名解析逻辑 |

自建服场景下 **不要还原** 上述 patch，否则可能仍尝试连接 Telegram 官方基础设施。

---

## 5. 后端检查

```bash
bash teamgram/scripts/start.sh
lsof -i :10443 -i :11443
nc -zv <服务器IP> 10443
```

日志：`teamgram/logs/gnetway.log`、`session.log`。

---

## 6. API 凭证

编译参数（或 `Telegram/cmake/telegram_options.cmake` 默认值）：

```bash
-D TDESKTOP_API_ID=你的api_id
-D TDESKTOP_API_HASH=你的api_hash
```

须与 [my.telegram.org](https://my.telegram.org) 申请的一致；与 iOS / Android 建议统一。

---

## 7. 测试登录

- 企业版测试环境常见验证码：**12345**
- 若握手失败：优先查 RSA 公钥与 IP/端口
- 若仍连官方：检查 `mtproto_dc_options.cpp` patch 是否完整

---

## 8. 与其他端对齐

| 客户端 | 配置位置 |
|--------|----------|
| Desktop | `mtproto_dc_options.cpp`（IP/端口/RSA）+ CMake API 参数 |
| Android | `ConnectionsManager.cpp` + `BuildVars.java` |
| iOS | `TeamgramGatewayHost.swift` |
| Web | `telegram-tweb/docs/服务端对接配置.md` — `.env` + `dcConfigurator.ts` |
